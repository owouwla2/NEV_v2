## 3. 推荐演示动线（约 12-15 分钟）

1. **admin 登录** → 仪表盘：四张统计卡真实数据（商品 3 / 电池 4 / 碳积分 1062.5 / 链上事件 13）。
2. **电池溯源 → 电池注册**（切 producer1）：表单预填，点"注册 + 上链"→ 返回 txHash/dataHash（现场新增一块电池，链块号 +1）。
3. **电池流通**（distributor1）：调拨入库 → IN_USE 事件上链。
4. （retailer1）零售售出给 consumer1 → SOLD，所有权转移。
5. **商城管理 → 商品管理 / 订单管理**（merchant1）：3 个商品、发货订单。
6. **consumer1**：商品加购 → 下单（三态：PENDING/PAID/COMPLETED）→ 确认收货 → **碳积分账户 +1062.5**。
7. **以旧换新**：consumer1 提交换新申请 → recycler1 评估处理（SOH/估价）→ consumer1 接受 → **链上 RECYCLED**。
8. **回收管理 → 回收处理**（recycler1）：处理历史（2 完成 + 1 待接受）。
9. **区块链 → 链上溯源**：输入 `NEV-DEMO-1109-001` → 每条事件当场调链 verifyEvent，`overallVerified=true`。
10. **碳核算**：碳足迹查询（5 阶段明细）/ 排放因子库（15 条 GB/T 24067 因子）/ 碳积分账户。
11. **区块链 → 合约配置**：LifecycleTrace `0xf717...7b08`，7 角色钱包已授权。
12. **公开扫码**（无需登录，可手机演示）：`http://localhost:8120/scan/NEV-DEMO-1109-001`。
13. **系统管理/监控**（admin）：用户管理 9 账号、登录日志、在线用户、缓存监控等均为真实框架数据。

## 4. 注意事项

- **角色权限**：`回收处理`、`评估处理` 等角色页需对应角色登录；admin 打开会显示"权限不足"类错误提示（属预期，SaCheckRole 生效的表现）。
- **在线用户/操作日志**：演示操作会实时累积，数字随演示增长是加分项。
- **重置演示数据**：重跑 `backend/script/sql` 六件套重导 + 重跑演示数据脚本（scratch `demo-data.ps1`，注意换新的 trace 前缀避免与链上历史冲突）。
- **后端改了模块代码**：先 `mvn install -pl nev-modules/<module> -am -DskipTests` 再重启（详见 HANDOFF §7.7）。
