### 任务 3：补充商城订单流程测试

建议按以下顺序验证：

```text
merchant 登录
→ 商品上架
→ consumer 查询商品
→ consumer 加入购物车
→ consumer 创建订单
→ consumer 模拟支付
→ merchant 发货
→ consumer 确认收货
→ 电池触发 SOLD
→ consumer 获得碳积分
```

重点检查：

- 商品库存是否扣减；
- 订单状态是否为 `PENDING → PAID → SHIPPED → COMPLETED`；
- 确认收货是否重复触发 SOLD；
- 碳积分账户和流水是否更新；
- 订单关联电池是否能在公开扫码中显示。

### 任务 4：补充以旧换新流程测试

建议按以下顺序验证：

```text
consumer 提交换新申请
→ recycler 查询待评估申请
→ recycler 录入 SOH 和报价
→ consumer 接受评估
→ 电池触发 RECYCLED
→ 换新申请完成
```

同时测试拒绝分支：

```text
SUBMITTED / EVALUATED → REJECTED
```

重点检查：

- 申请状态转换是否正确；
- 只有 recycler 能够评估；
- 只有申请所属 consumer 能够接受或拒绝；
- 回收事件是否成功上链；
- 公开扫码是否显示 RECYCLED；
- 以旧换新是否重复提交或重复接受。

### 任务 5：补充碳积分测试

重点验证：

- 订单确认收货后是否增加积分；
- 以旧换新完成后是否增加或记录积分；
- 碳积分账户余额是否与流水余额一致；
- 重复确认订单是否重复发放积分；
- 碳足迹五阶段合计是否等于总碳排放。
